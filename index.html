Starver
GitHub Repository
v1.0.0 — Open Source Python Tool

Бесшовное перенаправление
запросов приложений

Удобный локальный HTTP-прокси и редиректор со встроенной панелью управления. Написан полностью на стандартной библиотеке Python.

Download from GitHub

# Запуск через CLI:

$ python version_redirect.py serve --old http://127.0.0.1:8080 --new http://127.0.0.1:9000


# Или запуск Web UI панели:

$ python starver_ui.py

> Starver Dashboard запущен на http://127.0.0.1:7860

🔀

Прокси и Redirect

Поддержка режимов Proxy (скрытая пересылка с сохранением заголовков) и HTTP 301/302 Redirect.

🎛️

Starver Dashboard

Встроенный современный Web UI для управления перенаправлением и просмотра журналов в реальном времени.

🚀

Zero Dependencies

Работает исключительно на стандартной библиотеке Python 3.10+. Никакой установки сторонних пакетов.

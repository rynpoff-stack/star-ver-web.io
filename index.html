Инженерная точность в каждой детали

Ничего лишнего — только чистый Python, высокая скорость и полный контроль над локальным трафиком.

Встроенный Web Dashboard на localhost

Запустите starver_ui.py и управляйте сервером прямо из браузера на порту 7860. Запускайте и останавливайте прокси в один клик, тестируйте пути перед запуском и наблюдайте за логами запросов в реальном времени.

Прозрачный Proxy и Redirect

Поддерживает все HTTP-методы (GET, POST, PUT, PATCH, DELETE) с бережной передачей тела запроса и заголовков, а также мгновенные 301/302 редиректы.

Ноль зависимостей

100% стандартная библиотека Python 3.10+. Не нужно устанавливать тяжелые фреймворки или настраивать сложный Nginx для локальных тестов.

JSON-конфигурация

Храните настройки портов, хостов и маршрутов в чистом config.json для мгновенного развёртывания в любом окружении.

Мгновенная диагностика

Команда check покажет точный итоговый URL и HTTP-статус для любого сложного пути с query-параметрами ещё до запуска.

Готовы запустить прямо сейчас?

Клонируйте репозиторий и откройте панель управления одной командой.

git clone https://github.com/rynpoff-stack/starver.git && cd starver && python starver_ui.py

100% Легитимный и безопасный Open-Source инструмент

Starver работает исключительно на локальном интерфейсе (127.0.0.1) для маршрутизации ваших собственных сервисов. Открытый исходный код без сетевых сканеров и скрытых модулей.
